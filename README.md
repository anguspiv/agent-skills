# agent-skills

Skills for AI coding agents, written by [@anguspiv](https://github.com/anguspiv).
One repo, two ways in:

```bash
# Claude Code
claude plugin marketplace add anguspiv/agent-skills
claude plugin install anguspiv-skills@anguspiv-skills

# skills.sh (Claude Code, Cursor, Codex, OpenCode, and others)
npx skills add anguspiv/agent-skills
```

Browse the catalog at <https://anguspiv.github.io/agent-skills/>.

## How this repo works

- `skills/<name>/SKILL.md` is the only thing written by hand. It follows the
  [Agent Skills specification](https://agentskills.io/specification).
- `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, the table
  above, and the Pages index are generated by `npm run catalog`.
- Releases are cut by release-please from conventional commits. Each release
  ships a plugin zip and one `.skill` file per skill.

See [docs/contributing.md](docs/contributing.md) to add a skill and
[docs/ideas.md](docs/ideas.md) for the backlog.
